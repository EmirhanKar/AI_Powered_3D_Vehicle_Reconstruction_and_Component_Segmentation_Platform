─── JANT YÜKLEME YÖNTEMLERİ ──────────────────────────────────

  YÖNTEM 1: Swagger UI Üzerinden (Tek tek)
  ─────────────────────────────────────────
  1. Backend sunucusunu başlat:
     cd Backend && uvicorn app.main:app --host 0.0.0.0 --port 8000

  2. Tarayıcıda aç: http://localhost:8000/docs

  3. POST /plugins/jants endpoint'ini bul → "Try it out" tıkla

  4. Parametreleri gir:
     • model_name: "BBS RS"
     • category:   "sport"
     • image:      [Dosya Seç] → jant görseli (PNG/JPG/WEBP, şeffaf arka plan önerilir)

  5. Execute tıkla → 201 Created dönerse başarılı


  YÖNTEM 2: cURL ile (Toplu yükleme scripti)
  ───────────────────────────────────────────
  Tek jant yükleme:
  
    curl -X POST "http://localhost:8000/plugins/jants" \
      -F "model_name=BBS RS" \
      -F "category=sport" \
      -F "image=@jant_resimleri/bbs_rs.png"

  Toplu yükleme (PowerShell scripti):
  
    $jantlar = @(
      @{ name="BBS RS";        cat="sport";   img="bbs_rs.png" },
      @{ name="Vossen VFS-1";  cat="sport";   img="vossen_vfs1.png" },
      @{ name="Rotiform BLQ";  cat="sport";   img="rotiform_blq.png" },
      @{ name="OZ Racing";     cat="sport";   img="oz_racing.png" },
      @{ name="Enkei RPF1";    cat="sport";   img="enkei_rpf1.png" },
      @{ name="Work Meister";  cat="classic"; img="work_meister.png" },
      @{ name="SSR SP1";       cat="classic"; img="ssr_sp1.png" },
      @{ name="TE37 Saga";     cat="classic"; img="te37_saga.png" },
      @{ name="Fuel Rebel";    cat="suv";     img="fuel_rebel.png" },
      @{ name="Method 701";    cat="suv";     img="method_701.png" }
    )

    foreach ($j in $jantlar) {
      $form = @{
        model_name = $j.name
        category   = $j.cat
      }
      $file = Get-Item "jant_resimleri/$($j.img)"
      Invoke-RestMethod -Uri "http://localhost:8000/plugins/jants" `
        -Method POST -Form $form `
        -InFile $file.FullName
      Write-Host "Yuklendi: $($j.name)"
    }


  YÖNTEM 3: Python scripti ile (Önerilen)
  ────────────────────────────────────────
  Backend/seed_jants.py dosyası oluştur:

    import asyncio
    from app.database.db import get_session
    from app.database.models import Jant
    from PIL import Image
    import os, shutil

    JANT_DATA = [
        {"model_name": "BBS RS",       "category": "sport"},
        {"model_name": "Vossen VFS-1", "category": "sport"},
        {"model_name": "Rotiform BLQ", "category": "sport"},
        {"model_name": "OZ Racing",    "category": "sport"},
        {"model_name": "Enkei RPF1",   "category": "sport"},
        {"model_name": "Work Meister", "category": "classic"},
        {"model_name": "SSR SP1",      "category": "classic"},
        {"model_name": "TE37 Saga",    "category": "classic"},
        {"model_name": "Fuel Rebel",   "category": "suv"},
        {"model_name": "Method 701",   "category": "suv"},
    ]

    async def seed():
        async for db in get_session():
            for data in JANT_DATA:
                img_path = f"jant_resimleri/{data['model_name'].lower().replace(' ', '_')}.png"
                
                # Görseli uploads klasörüne kopyala
                dest_dir = "uploads/plugins/jants"
                os.makedirs(dest_dir, exist_ok=True)
                dest = f"{dest_dir}/{data['model_name'].lower().replace(' ', '_')}.png"
                
                if os.path.exists(img_path):
                    shutil.copy2(img_path, dest)
                
                jant = Jant(
                    model_name=data["model_name"],
                    category=data["category"],
                    image_url=dest if os.path.exists(dest) else None
                )
                db.add(jant)
            
            await db.commit()
            print("Tüm jantlar yüklendi!")

    asyncio.run(seed())


─── JANT GÖRSELLERİ HAZIRLAMA ────────────────────────────────

  ÖNEMLİ KURALLAR:
  • Arka plan ŞEFFAF (transparent PNG) olmalı
  • Çözünürlük: 512x512 px önerilir
  • Format: PNG (şeffaf arka plan için)
  • Jant tam merkezde ve kare çerçeveye sığacak şekilde olmalı
  • Dosya boyutu: maksimum 500KB

  DOSYA YAPISI:
    jant_resimleri/
    ├── bbs_rs.png
    ├── vossen_vfs1.png
    ├── rotiform_blq.png
    ├── oz_racing.png
    ├── enkei_rpf1.png
    ├── work_meister.png
    ├── ssr_sp1.png
    ├── te37_saga.png
    ├── fuel_rebel.png
    └── method_701.png

  KATEGORİLER:
    • sport   → Spor jantlar (BBS, Vossen, Rotiform, OZ, Enkei)
    • classic → Klasik jantlar (Work, SSR, TE37)
    • suv     → SUV/Off-road jantlar (Fuel, Method)
